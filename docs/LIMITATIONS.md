# Limitations

- The default release uses a small repository-curated snapshot with incomplete provenance.
- The optional Chroma archive is not populated or verified in the release profile.
- Live provider, enrichment, local-model, cloud-model, and ingestion paths are disabled and unverified.
- Team/player archive responses can preserve their type while explicitly reporting unavailable statistics.
- Subjective analysis is not an official ranking, prediction, betting recommendation, or fantasy recommendation.
- In-memory sessions are single-process, unauthenticated, and non-durable.
- No public deployment, scaling, availability, data licensing, or production-security claim is made.
- Socket.IO and SSE are implemented but do not yet have load or reconnect evidence.
